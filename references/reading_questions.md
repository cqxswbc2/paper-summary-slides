# 按论文类型的精读问题

先回答这些问题（可以写在草稿里），再压缩成页面字段。每个回答都要能指出原文位置。

## 所有论文都要回答

1. **研究问题**：作者想解释什么现象、解决什么问题？用一句话写，最好是一个能用"是 / 否 / 取决于"回答的问题。
2. **答案**：论文给出的答案是什么？先给一个短结论（answerLead，例如 "Only up to a point."），再用一两句话说清条件。
3. **两个关键概念**：理解这个问题必须先知道的两个词是什么（例如 growth 与 monetization、follower count 与 engagement）？各用一两句白话定义，写清在论文里怎么衡量。
4. **管理学启示**：谁（企业、品牌、平台、消费者）据此应该怎么做？只写一句。

## 理论文章（theory）

1. **决策者**：模型里有哪些主体？谁是主要决策者？不做策略选择的主体（只是需求曲线）也可以列，但要写明"不做策略选择"。
2. **权衡**：每个决策者面临的主要两难是什么？写成"A vs. B"。
3. **决策变量**：每个决策者选择什么？页面上要展示的是决策变量，不是外生参数。
4. **博弈顺序（timing）**：谁先动、谁后动、信息何时揭示？压缩成 3–5 步。目标函数（例如"最大化贴现总利润"）写在 timing 那一行。
5. **主要结果**：最核心的命题是什么？成立需要什么条件（用文字表述，不写参数符号）？
6. **机制**：为什么会这样？用两三条白话解释，不藏在代数后面。
7. **比较静态与边界**：关键因素变化时结论怎么变？扩展模型里结论在哪些情况下反过来？

可借鉴的分析顺序：现象 → 常规看法 → 缺失的摩擦 → 最小模型 → 基准结果 → 加入摩擦后的结果 → 命题 → 直觉 → 含义。

## 实证文章（empirical）

1. **数据来源**：什么平台、谁提供、时间范围、样本量（帖子数、人数、活动数）；另有实验时写清实验个数与样本量。
2. **主要回归模型**：被解释变量对哪些变量回归，函数形式（例如加平方项检验倒 U 形），固定效应、聚类、内生性处理（工具变量、Heckman 选择修正、重加权）。用一两句白话写。
3. **因变量与自变量**：各自怎么定义和测量（计数、比例、对数、词典打分、人工编码）。调节变量、中介变量只列关键的。
4. **结论**：哪个 X 怎样影响哪个 Y，效应多大（用论文报告的弹性、百分比、拐点）。
5. **机制**：作者如何解释，是检验过的中介还是推测？推测要写明 "Likely reason" 或 "Possible reasons"。
6. **证据强度**：观察数据只能说明相关的，要写明；因果证据来自哪项研究（实验、自然实验）。

## 质性研究（qualitative）

1. **材料**：访谈对象与人数、时间、补充材料（播客、行业文章、平台说明）。
2. **方法**：编码方式（开放、主轴、选择性编码）、理论视角。
3. **关键概念**：3–5 个核心概念，各自的含义及在论证中的作用。
4. **主要发现**：谁和谁在什么问题上看法不同，结果对谁有利。
5. **机制**：作者如何解释这些发现。

## 概念性论文（conceptual）

1. **材料**：综述了哪些研究、行业报告、案例。
2. **框架**：提出了哪几个视角或环节。
3. **关键概念**：框架里的核心概念及作用。
4. **主要观点与冲突**：各方目标在哪里一致、在哪里冲突。
5. **论文没有给出的**：例如没有给出收入分成比例，要如实写明，不要补。

## 和项目问题的联系

页面上不写项目推论。论文与你自己研究问题的联系是推断，写在备注里或口头说明，并标明"论文未研究"。

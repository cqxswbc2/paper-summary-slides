# 检查清单

## A. 版面（每页看导出图片）

- [ ] 文字没有超出框、没有被下方色块遮住（最常见的是变量表最后一行、机制栏最后一句）
- [ ] 标题两行时不压作者行；作者行没有折到下一行
- [ ] 博弈顺序每格不超过 3–4 行
- [ ] 图表标题只有一行；柱状图标签按原精度显示；图例不挡图
- [ ] 同类页面的标题、栏目位置一致

## B. 内容（逐页）

- [ ] 问题有答案，答案和主要结果一致
- [ ] 概念卡定义了理解问题必需的两个概念
- [ ] 理论文章：决策者、权衡、决策变量、博弈顺序都有；条件用文字写，没有参数符号
- [ ] 实证文章：数据来源、样本量、回归模型、因变量与自变量的测量都有；相关与因果说清
- [ ] 没有 she/he，没有空话和装饰性措辞
- [ ] 管理学启示只有一句

## C. 引用与数字（抽查，越多越好）

AI 整理的引用和数字常见三类错误，需要回原文核对：

1. **编造**：文献不存在，或数字在原文里找不到。
2. **信息不准**：题目、年份、卷期页码、第一作者之后的作者写错。
3. **观点误传**：原文没有这样说，或把作者的推测写成了检验过的结论。

核对方法：

- [ ] 每页至少核对一个关键数字（样本量、效应大小、拐点）是否与原文表格或正文一致
- [ ] DOI、卷期页码与出版社页面一致；工作论文版的卷期页码来自 Crossref 时，在备注说明
- [ ] 作者的推测标为 "Likely reason" 或 "Possible reasons"
- [ ] 原文两处数字冲突时（例如正文与表格不一致），备注写明采用了哪一个

## D. 交付前

- [ ] `node scripts/check_paper.js papers/*.js` 全部 OK
- [ ] PowerPoint 能打开，页数正确
- [ ] 向用户汇报：哪些页用了工作论文版或作者版、哪些数字没回原文核对、哪些论文缺全文
